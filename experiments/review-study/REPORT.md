# 좋은 책 리뷰는 어떤 글인가 — 조사 보고

## 한 줄 결론

좋은 리뷰는 요약이 아니라 **근거 있는 판단**입니다. 세 갈래 조사가 모두 같은 곳을 가리켰습니다.

- 비평가들은 "리뷰는 논증이다"라고 말합니다.
- 연구는 "깊이(구체성)가 가장 일관된 유용성 요인"이라고 말합니다.
- 서점 표본에서는 길이를 맞춰도 공감 상위 리뷰에만 남는 차이가 있었습니다. **평가·비판이 있느냐**와 **나열형이 아니냐**입니다.

## 1. 세 갈래가 공통으로 가리키는 것

| 원칙 | 작법·비평 (craft) | 연구 (helpfulness) | 서점 표본 (bookstore) |
|---|---|---|---|
| **판단이 있어야 한다** | 요약이 아니라 논증[craft 1] | 논증 품질·진단성이 유용성을 높임 | 한계·비판 top 46% vs ordinary 20%. 1,000자 이상끼리도 46% vs 29% |
| **근거는 구체적으로** | 인상어 대신 대목·인용[craft 3] | 깊이(길이)가 가장 일관된 양(+) 요인. 책은 경험재라 효과가 작고, 너무 길면 줄어듦 | 근거가 붙은 반론("표본 수가 100을 넘지 못한다", 번역어 지적) |
| **요약은 뼈대만** | 판단에 필요한 만큼만[craft 1·9] | 지식재는 내용 정보가 진단성을 줌 | top 75%가 요약을 담지만 비중 중앙값 40%. 요약·목차 나열형은 top 7% vs ordinary 21% |
| **나를 드러내되 책으로 돌아온다** | 서평자의 목소리[craft 11], 독서 기록은 '왜 나에게 남았나'[craft ②] | 리뷰어 맥락(독서 이력)이 신뢰 신호 | 계기·경험 + 평가 동시 top 60% vs 41% |
| **공정하게** | 저자가 하려던 것을 기준으로[craft 2], 주례사 금지[craft 4] | 그 책 평균에 가까운 별점일수록 유용. 별점과 논조가 어긋나면 신뢰가 깎임 | top이 별점은 더 박함(3점 이하 21% vs 11%) |
| **맥락과 연결** | 선행 논의·관련서 속에서 평가[craft 7] | (직접 근거 없음) | 다른 책·사상과 잇기, 이어 읽을 책 |
| **독자에게 쓸모 있게** | 읽을지 말지, 누구에게 권할지[craft 8] | 첫 문장 품질(미리보기)이 중요할 수 있음(추론) | 짧아도 공감 40 이상인 글은 모두 솔직한 비판이나 비추천 |

## 2. 서점 표본에서 본 것 (113개 = 알라딘 54, 예스24 59, 책 6권)

- **길이:** 중앙값 top 1,826자, ordinary 180자.
  - 다만 짧은 top(600자 미만) 12개 중 공감 40 이상인 5개는 모두 **솔직한 불만이나 비판**이었습니다("50쪽이면 될 책", "덮으면 1도 기억 안 난다").
- **길이를 맞추면(1,000자 이상끼리):** 요약·인용·경험의 차이는 거의 사라지고 **비판(46% vs 29%)**과 **나열형(7% vs 21%)**만 남습니다.
  - 긴 ordinary 글은 협찬 템플릿이나 개조식 학습 노트가 많았습니다.
- **좋은 리뷰의 흐름 세 가지:**
  - **공정한 요약 → 정면 반론:** 『팩트풀니스』, 2.5점인데 공감 33
  - **문학적 도입 → 자기 경험 → 주제 재정의:** 『도둑맞은 집중력』
  - **대비 틀 → 도식 요약 → 한계 → 다음 책:** 『총, 균, 쇠』
- **『하류사회』 리뷰도 top에 있었습니다:** 번역어 지적("단카이 세대를 '단괴 세대'로 번역"), 표본 비판이 담긴 구판 리뷰입니다. 신판 리뷰는 공감이 0–1개뿐입니다.

**표본의 한계**
- top과 ordinary는 쓴 시기가 다릅니다(top은 2010–2020년, ordinary는 대부분 2023–2026년).
- 코딩은 한 명이 했습니다.
- 칸당 표본이 26–30개라, 10%p 안팎의 차이는 우연일 수 있습니다.
- 연구가 짚었듯 공감 수는 노출 순위와 기간의 영향을 크게 받습니다.
- 그래서 이 결과는 경향으로만 읽습니다.

## 3. 용도별로 정리한 좋은 리뷰

| | 서점 독자 리뷰 | 비평형 서평 | 개인 독서 기록 |
|---|---|---|---|
| 독자 | 살까 말까 고민하는 사람 | 책과 쟁점에 관심 있는 교양 독자 | 나중의 나(와 블로그 독자) |
| 분량 | 1,500–3,000자 | 4,000–8,000자 | 제한 없음(공개 글은 1,500–4,000자) |
| 첫머리 | 한 문장 총평 + 누구에게 권하나 | 쟁점과 서평자의 테제 | 읽게 된 계기·날짜 |
| 요약 | 핵심 주장 3–5문장 | 논증 구조를 짧고 정확하게 | 몇 줄 |
| 중심 | 좋았던 점·아쉬운 점을 구체적 대목으로 | 강점·약점 분석, 근거 검토, 관련서 비교, 반론과 대안 | 남은 구절과 이유, 동의·반대, 내 경험과 연결 |
| 끝 | 추천·비추천 대상, 함께 읽을 책 | 종합 판단, 이 책의 의미 | 다시 읽을 곳, 남은 질문 |
| 피할 것 | 목차·출판사 소개 반복(알라딘은 내림), 한 줄 칭찬, 별점과 어긋난 논조 | 주례사, 인상 비평, 하지 않은 일 탓하기 | 요약만 옮기기, 유행하는 해석 빌리기 |

## 4. book-companion에서 리뷰를 쓸 때 쓸 수 있는 재료

이 프로젝트는 일반 리뷰어가 갖기 어려운 근거를 이미 갖고 있습니다.

| 좋은 리뷰의 조건 | 이미 있는 재료 |
|---|---|
| 정확한 요약 | `index.md` L0, 장별 `study.md` L1 |
| 근거 있는 비판 | `insights.md`의 반박(강도·근거·재반박), `synthesis.md` |
| 구체적 대목·인용 | `source.md` 앵커(인쇄 쪽 번호로 환산) |
| 맥락·관련서 | `research/`(서평·원서 반응·후속작), 참고문헌 장 |
| 판본·번역 언급 | `synthesis.md` '원문·번역에 대해', 구판·신판 차이 |
| 공정성 | 저자 측 재반박, 저자가 스스로 인정한 한계(후기) |
| 나의 관점(개인 기록형) | 사용자와 `/bookc-open`으로 나눈 대화가 있다면 거기서. 없으면 사용자에게 읽은 계기와 인상을 묻는다 |

'나의 경험'은 Claude가 지어낼 수 없습니다. 개인 기록형과 서점 리뷰형의 "읽게 된 계기·경험" 부분은 사용자의 말을 받아서 쓰거나, 비워 둔 자리로 남겨야 합니다.

## 5. 제안: 7단계 '리뷰'

- **스킬:** `/bookc-7-review [책] [용도]`
- **선행 단계:** 6단계(인사이트)
- **결과물:** `reviews/store.md`, `reviews/critical.md`, `reviews/log.md`
- **쓰는 순서**
  1. 사용자에게 두 가지를 짧게 묻습니다: 읽게 된 계기와 인상, 권하고 싶은 독자.
  2. 대화 기록이 있으면 그것을 씁니다.
  3. 용도별 구조(3절)로 초안을 씁니다.
  4. 아래 체크리스트로 스스로 점검한 점수표를 붙입니다.
- **체크리스트 (자동 점검)**
  - 테제가 첫 단락에 있는가
  - 요약 비중이 40% 이하인가
  - 근거가 붙은 판단이 3개 이상인가
  - 반박이 1개 이상이고, 저자 측 재반박도 공정하게 다뤘는가
  - 인용은 한 문장 이하이고 3개 이내인가(저작권)
  - 별점과 논조가 일치하는가
  - 추천·비추천 대상을 밝혔는가
  - 목차 나열이나 출판사 문구 반복이 없는가
- **진행 현황 페이지:** '리뷰' 탭에 세 편을 보여 주고, 체크리스트 점수를 막대로 표시합니다.
