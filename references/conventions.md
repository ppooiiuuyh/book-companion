# Book Companion 규약 (v0.3)

모든 스킬·스크립트·교정 작업은 이 규약을 따른다.

## 1. 층 분리

| 층 | 위치 | 들어가는 것 | 들어가면 안 되는 것 |
|---|---|---|---|
| 원문 | `NN_장/source.md`, `img/` | 책에 있는 글자와 도표 판독(축·수치·라벨을 옮긴 것) | 요약, 평가, 해석 |
| 요약 | `NN_장/study.md` | L1 장 요약, L2 절 요약(쪽 범위 필수) | 원문에 없는 주장 |
| 통독 | `reading/` | Claude의 해석·메모·질문 | — |
| 외부 | `research/` | 리뷰·비평 (출처 URL 필수) | 출처 없는 주장 |
| 기계 | `_work/` | 추출 이미지, OCR, 레이아웃, 교정 기록 | — |

## 2. 주소

- 쪽: `p{3자리}` (PDF 쪽 번호, 1부터) — 예 `p045`
- 블록: `p{쪽}-b{번호}` — 예 `p045-b3` (쪽 안에서 위→아래 순번)
- 이미지: `img/p{쪽}-b{번호}_{fig|tab|photo|illu}.png`
- 절: `§{장}.{절}` — 예 `§1.3`
- source.md 안에서 쪽 시작은 `<!-- p045 -->`, 블록 시작은 `<!-- p045-b3 -->`

## 3. 교정(review) 원칙

1. **이미지가 정답이다.** 초벌 OCR은 참고일 뿐이며, 이미지와 다르면 이미지를 따른다.
2. **책 그대로 옮긴다.** 책의 오탈자·띄어쓰기 누락도 고치지 않는다(명백한 OCR 오류만 고친다).
3. 따옴표·괄호는 책의 기호를 쓴다: ‘ ’ “ ” 『 』 「 」, 범위 대시는 `–`.
4. 괄호 속 작은 글씨(주석·출처)는 본문에 그대로 둔다.
5. 판독 불가는 `[?]`, 추정은 `[?추정어]`로 남긴다.
6. 사진 속 글자(간판·트럭 등)는 본문이 아니므로 지운다.
7. 도표는 `figures`에 넣고: 제목, 주·출처(책의 글자 그대로), 판독 데이터(표), 판독 설명(보이는 것만, 해석 금지).
8. 새 용어는 `glossary` 제안에 넣는다.
9. **각주 번호**: 본문의 위첨자 번호는 해당 줄 `fix`에 `[^n]`으로 적는다. 책 끝 주석 장이 있으면 정의는 `_work/notes.json`에서 자동으로 채워지므로 `footnotes`는 비워 둔다. 쪽 아래 각주(책 끝 주석이 없는 책)는 그 줄을 `delete`하고 `footnotes: {"n": "내용"}`에 옮긴다.
10. **혼동형**: 이 책에서 되풀이되는 OCR 오인식(예: 중류→증류)을 발견하면 `confusions: {"오류형": "올바른 형"}`에 적는다. lint가 전 장에서 찾아 준다.
11. 장 표지 쪽(`title_pages`)은 교정하지 않는다.

## 4. review JSON 형식 (`_work/review/pNNN.json`)

```json
{
  "page": 16,
  "fix":    {"L12": "교정된 줄 전체"},
  "delete": ["L03"],
  "insert_after": {"L05": ["빠진 줄"]},
  "kind":   {"L01": "heading", "L20": "caption"},
  "para_start": ["L22"],
  "no_para_start": ["L30"],
  "join":   {"L07": "space"},
  "figures": [{
     "kind": "fig", "lines": ["L01","L02"], "bbox": null,
     "title": "도표 1-1 …", "notes": ["주: …", "출처: …"],
     "data_md": "| 국가 | 값 |\n|---|---|", "desc": "보이는 것만 적은 판독 설명"
  }],
  "unsure": ["L09"],
  "glossary": [{"term": "하류", "note": "저자의 조어. 의욕·능력이 낮은 계층"}],
  "confusions": {"증류": "중류"},
  "memo": "교정자 메모(선택)"
}
```

- `kind` 값: `heading`(소제목 ##), `subheading`(하위 소제목 ###), `title`(장 제목), `body`, `caption`(사진 캡션), `list`, `note`(각주·주), `drop`(버림)
- `join`: 해당 줄 끝과 다음 줄을 이을 때 `space` / `nospace` 강제. 지정이 없으면 형태소 분석기로 결정.
- 줄 번호는 `_work/draft/pNNN.md`의 번호를 쓴다.

## 5. 요약 원칙 (study.md)

- L2(절) → L1(장) → L0(책) 순서로, 한 층 아래만 근거로 쓴다.
- 모든 L2 요약에 쪽 범위와 원문 앵커 링크를 단다.
- 문장마다 `[주장]` `[근거]` `[해석]`을 구분한다.


## 6. 통독 원칙 (reading/)

- 1차(장별 요약·도표 읽기)는 그 장 원문만 근거로 하므로 장끼리 병렬로 한다.
- 2차(통독 메모)는 앞에서부터 한 장씩 차례로 읽는다. 앞 장 메모와 `reading/_carry.md`(누적 맥락), 그 장의 study.md를 먼저 읽는다.
- 메모는 원문 앵커(`p045-b3`)로 근거를 단다. 외부 조사(`research/watchlist.md`)의 질문에 답이 나오면 연결한다.
- 저자의 주장과 Claude의 해석을 섞지 않는다.
